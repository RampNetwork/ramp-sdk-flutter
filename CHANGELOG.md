# Changelog

## 5.0.0

* Fresh package scaffolding via `flutter create --template=package` (Flutter
  3.44) with an `--empty` iOS/Android example app.
* Port of the Ramp Flutter WebView SDK: `Configuration`, `RampFlutter`,
  widget events, `sendCrypto`, and forked `webview_flutter` `onCreateWindow`
  handling for `target=_blank` / `window.open`.
